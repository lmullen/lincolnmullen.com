There’s not been a lot of optimism about the web recently, but Paul Ford [points out](https://ftrain.com/aboard-the-web-is-more-than-enough) that web technologies designed for teams of software engineers can now be used by individuals:

> The high tax of building for app stores seems less worth paying when you can just test an idea in the world from a web server for $0 after a couple weeks. Perhaps Mozilla should take another swing at launching a mobile phone! (Forget I mentioned that.) In any case, what used to be a large industrial process is now a personal one, if you so desire. Web browsers enable incredibly rich app development—and that’s radically easier than it used to be.

But then, this shrewd observation:

> It’s a mixed blessing. I’ve been a writer for years, and software development feels more and more like writing to me every passing week. The awkward part of the comparison is, in general, people do not want to pay writers any money at all. As a writer, you get used to it. But for software people, being perpetually devalued is pretty novel.
