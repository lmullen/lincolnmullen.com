{{- /* Responsive raster with a 1x/2x WebP srcset — the shared resize logic behind the image and figure shortcodes and the homepage images. Callers handle GIF/SVG passthrough and any link wrapper. Call with a dict: res the image resource width 1x display width in px (2x is derived) class img class alt alt text (already plainified) lazy set true to add loading="lazy" Never upscales: each width is capped at the source width, and the 2x candidate is dropped when the source is no wider than the 1x image. */ -}} {{- $w1 := .width -}} {{- if lt .res.Width $w1 }}{{ $w1 = .res.Width }}{{ end -}} {{- $w2 := mul 2 .width -}} {{- if lt .res.Width $w2 }}{{ $w2 = .res.Width }}{{ end -}} {{- $regular := .res.Resize (printf "%dx webp" $w1) -}} {{- $srcset := printf "%s 1x" $regular.RelPermalink -}} {{- if gt $w2 $w1 -}} {{- $retina := .res.Resize (printf "%dx webp" $w2) -}} {{- $srcset = printf "%s, %s 2x" $srcset $retina.RelPermalink -}} {{- end -}}
